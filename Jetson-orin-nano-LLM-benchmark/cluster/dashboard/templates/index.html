엣지 워커 찾기

Head와 같은 사설 LAN에서 SSH가 열린 기기를 찾습니다. 기기를 선택한 뒤 공개 키 인증과 Jetson/Pi 환경을 확인하고 자동 준비합니다.

연결된 기기검색을 시작하세요.
아직 검색하지 않았습니다.
HEAD SSH PUBLIC KEY키가 아직 생성되지 않았습니다.

최초 한 번 이 키를 워커의 ~/.ssh/authorized_keys에 등록해야 합니다. SSH 또는 sudo 비밀번호는 대시보드가 받거나 저장하지 않습니다.

CLUSTER SETTINGS

클러스터 설정

신뢰할 수 있는 로컬 네트워크에서는 대시보드와 워커 API 인증을 모두 꺼둘 수 있습니다. 여러 사용자가 같은 LAN을 쓰거나 외부 접근 가능성이 있으면 필요한 보호 기능을 켜세요.

현재 꺼짐 · 토큰 없이 대시보드 접속
보안을 켜는 순간 브라우저가 잠기지 않도록 기존 토큰을 한 번 확인합니다. 설정 파일에는 저장하지 않습니다.
현재 꺼짐 · 신뢰 LAN 전용 모드

워커 API 인증을 변경할 때만 연결된 노드 API가 자동 재시작됩니다. 대시보드 인증은 즉시 적용되며 기본값은 꺼짐입니다. 워커 보안이 켜진 동안에는 인증되지 않은 llama.cpp RPC 모델 분할 실험이 차단됩니다.
